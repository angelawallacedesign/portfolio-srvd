# Designing with AI Hero — Pass 5

Pass 5 branches directly from Pass 3, preserving its approved scale, presentation primitives, content, entrance choreography, abstract workflow, and reduced-motion behavior.

It relocates the existing technical blueprint SVG from the outer stage into the foreground panel shell. The blueprint is clipped to the panel, moves with the panel entrance, and is softened beneath a translucent white surface so it supports rather than competes with the hero content. Eyebrow, title, and body are vertically stacked; the body uses a copy-and-CTA column beside the workflow visual on desktop. The workflow is hidden at the responsive breakpoint so the primary content can use the full panel width. The outer field retains its gradient and sparse ambient activity without the blueprint drawing.

Persistent motion uses offset durations and sparse events. Reduced-motion users receive the complete final composition with the documented code/specification state visible and all looping motion removed.

Open `index.html` for the isolated preview and integration notes. Use `component.html` with the shared global token, local token, component, and module stylesheets.
