# AGENTS.md

This project uses gated implementation passes.

Before every pass:

- Read this file.
- Read `/docs/00-overview.md`.
- Read the current pass instructions.
- Read the previous pass `PASS_REPORT.md`.

Before implementation begins:

- Summarize the approved scope.
- Summarize any approved weaving.
- Ask for confirmation before making changes.

After each pass:

- Update the current `README.md`.
- Create `PASS_REPORT.md`.
- Append unresolved technical decisions, deferrals, and out-of-scope items to `/docs/ENGINEERING_REVIEW.md`.
- Assign each new item a sequential `ENG-#` identifier.
- Stop for alignment.

Do not begin the next pass until the human explicitly confirms the pre-pass summary.
